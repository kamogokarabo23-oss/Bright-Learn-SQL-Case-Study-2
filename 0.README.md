BrightTV Viewership Analytics
📌 Project Overview
BrightTV Viewership Analytics – A case study focused on analyzing user profiles and viewing patterns to uncover trends, factors influencing content consumption, and strategies to grow BrightTV’s subscription base.

✅ Goal
Provide actionable insights that help BrightTV increase engagement and expand its user base through targeted content and CVM initiatives.

📂 Project Files
BrightTV Case Study PDF – Requirements and objectives.
Dataset (CSV) – User profiles and session-level viewership data.
SQL Scripts – Data cleaning, transformation, and analysis.
Analysis Notebook / Excel – EDA and visualizations.
Presentation File – Summary of insights and recommendations.

🛠 Tools Used
Snowflake SQL – Data cleaning and querying.
Python (Pandas, Matplotlib, Seaborn) – Analysis and visualization.
Canva – Dashboards and presentation design.
Miro – Workflow and planning.

🔍 SQL Workflow Summary
Initial Checks
Validate age ranges and timestamps.
Count records and check duplicates.

Data Cleaning
Remove duplicates from viewership → viewership_new.
Replace NULLs in user_profiles → user_profiles_new.
Add derived column Age_group.

Data Integration
Join user_profiles_new and viewership_new.
Analysis Queries
Viewership by Channel, Province, Race.
Time of Day and Duration Analysis.
Age Group, Gender, Monthly & Daily Trends.

🔍 Key Insights
Peak viewing occurs during weekday evenings.
Certain genres drive higher engagement among specific demographics.
Weekends show lower activity, indicating an opportunity for targeted campaigns.
High-value users consume more during prime time slots.

✅ Recommendations
Promote popular genres during low-consumption days.
Launch weekend engagement campaigns (special content drops).
Implement personalized recommendations based on user profiles.
Expand digital marketing to attract new subscribers.
